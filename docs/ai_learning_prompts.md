# Bili-Note · 内容增强提示词（读 md → 出 6 类学习物料） v3.1

> **形态**：用户给一份 markdown 文档（视频转录稿 / 学习材料），AI 读取后按 6 个方面的提示词生成学习物料，帮助用户「学习」并「深度理解」文档。
>
> **六类产出（一次文档 → 六份物料）**：
> ① 智能摘要　② 术语表与通俗解释　③ 知识导图　④ 动画表达（HTML 动画）　⑤ 补充知识　⑥ 深度学习与理解文档
>
> **通用约定**：
> - **输入**：一份 markdown 文档（转录稿）。文档若带 `mm:ss` 时间戳，所有引用应挂回时间戳；若没有，则按章节/段落定位。
> - **模型**：全部 6 类物料统一走**线上 AI 模型**（云端 API 大模型，具体模型由管线配置，建议统一给一个较强档位即可，无需本地 7B）。各提示词的解码参数见「模型路由与解码参数表」。
> - **输出**：各提示词指定格式（md / mermaid / 可运行 HTML / markdown），可直接落盘或喂给现有渲染流程。
> - **占位符** `{{doc_content}}` 为运行时注入的文档全文。
> - **不编造**：摘要、术语、导图、动画画面必须来自文档；外部/补充内容须标注来源与「可检索方向」，严禁编造论文标题、作者、年份、URL。
>
> 更细的统一口径（语气、术语一致、[mm:ss] 引用规范、📹/➕ 标签、各节长度目标、难度档位、few-shot 锚定）见下方「风格与合规护栏层」。
>
> **工程提示（承接评审结论）**：
> 本地 7B 对结构化/强推理环节力不从心，故本文件在下方提供四块脚手架：**模型路由与解码参数表**（谁来跑、怎么解码）、**输出契约表**（产出长什么样算合格）、**管线编排与质量门禁**（怎么跑通、失败怎么修）、**风格与合规护栏层**（全局口径：语气/术语一致/引用格式/来源标签/不编造/长度目标/难度档位/few-shot）。逐提示词脚注指向对应条目，管线按表执行即可。

## 模型路由与解码参数表

> 全部物料统一走**线上 AI 模型**（云端 API 大模型，具体模型由管线配置）。不再区分本地 7B / 强模型：④ 动画 HTML 这类高难环节直接在线上较强档位上生成即可。seed 固定以保证可复现；温度与 max_tokens 按环节微调。

| # | 提示词 | 推荐模型 | 温度 | seed | max_tokens | 依据 |
|---|--------|----------|------|------|-----------|------|
| ① | 智能摘要 | 线上模型 | 0.4 | 固定（如 20260820） | 1200 | 结构宽松；线上模型稳定 |
| ② | 术语表与通俗解释 | 线上模型 | 0.3 | 固定 | 1500 | 类比需少量创造，线上模型胜任 |
| ③ | 知识导图 | 线上模型 | 0.3 | 固定 | 1000 | mermaid 易错 → 靠门禁重试兜底 |
| ④ | 动画表达（HTML） | 线上模型（较强档位优先） | 0.2 | 固定 | 4000 | 生成合法 HTML/JS 需较强模型，线上直接给较强档位 |
| ⑤ | 补充知识 | 线上模型 | 0.3 | 固定 | 1500 | 反幻觉硬规则已约束编造 |
| ⑥ | 深度学习与理解文档 | 线上模型 | 0.3 | 固定 | 2000 | 结构化自测 + 推导，线上模型保质 |

**模型切换**：全部走线上模型后，不再有「本地 7B → 强模型」的升级逻辑；若某环节门禁连续失败，可在线上模型间切换到更强档位重试一次（见质量门禁）。

## 管线编排与质量门禁

### 执行编排（推荐 DAG）

```
转录稿.md
 ├─ Phase A（并行，线上）  ① 智能摘要 ─┐
 │                         ② 术语表    ├─→ ③ 知识导图（门禁）─┐
 │                         ⑤ 补充知识 ─┘                      │
 └─ Phase B（线上较强档位） ④ 动画表达 HTML（门禁，最重）──────┤
                                                            ├─→ ⑥ 深度学习与理解文档（门禁）
                                                            └─→ 学习包落盘 output/<video>/
```
- ① ② ⑤ 无相互依赖，可并行；③ 与 ④ 较重，单独跑；④ 用线上较强档位且最慢，可放最后。
- 顺序非强制：只要每份物料的校验通过，最终统一落盘即可。

### 质量门禁（Gate）

每份物料落盘前过一道校验；不通过则**回灌重试**，不让整包因单份失败而中断。

| # | 门禁动作 | 失败处理 |
|---|----------|----------|
| ① ② ⑤ ⑥ | 结构正则校验（标题/表格/分区是否存在、行数达标） | 重试 1 次（附"请严格按格式"）；仍失败标记 `[需人工复核]` |
| ③ | 抽取 mermaid 代码块，用 `mmdc --validate` 或轻量解析校验语法 | 把错误回灌："以下 mermaid 非法：<err>，请修正仅输出代码块"，重试 ≤2 次；仍失败切换到更强线上档位 1 次 |
| ④ | (1) 无外部资源：正则查 `src/href` 含 `http(s)://` 即拒；(2) HTML/JS 语法：headless 打开或 `node --check` 抽脚本；(3) 冒烟：加载无 `console.error`、动画能跑到 done | 把报错回灌："上版 HTML 在 <处> 报错：<err>，必须输出合法自包含 HTML"，重试 ≤2 次；仍失败切换到更强线上档位 1 次 |

### 回灌重试伪代码

```python
def generate(prompt, doc, tier, params, max_retry=3):
    model = pick_model(tier)                 # 线上模型（默认档 / 较强档）
    for attempt in range(1, max_retry + 1):
        out = llm(prompt, doc, model, params)
        err = validate(prompt.id, out)        # 见门禁表
        if err is None:
            return out                         # 通过，落盘
        # 回灌：把校验错误原样喂回，要求修复
        prompt = append(prompt,
            f"\n[第{attempt}次校验失败] {err}\n仅输出修正后的内容，不要解释。")
    # 兜底：切换到更强线上档位再试一次
    if tier != STRONG and prompt.strong_fallback:
        return generate(prompt, doc, STRONG, params, max_retry=1)
    raise GateError(prompt.id, "连续校验失败，需人工介入")
```

### 兜底原则
单份物料连续失败 → 保留最后一次输出并打标 `[需人工复核]`，其余物料正常落盘；整包不因单点失败而中断。

## 风格与合规护栏层（全局，适用于 ①–⑥）

> 本层提供「跨提示词的统一口径」，让六份物料在语气、术语、引用、来源、长度上保持一致，并附难度档位与 few-shot 锚定格式。单条提示词的 System Prompt 首行已声明继承本层，故提示词脱离本文件单独使用时口径仍自洽。

### 1. 语气与表达口径
- 以「你」向读者讲解：平实、清晰，先讲是什么/为什么，再讲怎么做。
- 反 AI 腔：不用「综上所述 / 值得注意的是 / 由此可见」等套话；不堆砌形容词与夸张修辞。
- 类比优先：能用一句话类比讲清的概念，先给类比，再补定义。

### 2. 术语一致性
- 同一术语全篇同一写法；首次出现给出全称与缩写（如「卷积 (Convolution，简称 Conv)」）。
- 跨物料一致：① 摘要、② 术语表、③ 导图、④ 动画旁白、⑥ 理解文档中，同一概念须同词同义。

### 3. 引用格式（时间戳）
- 引用原文/概念统一挂 `[mm:ss]`；无时间戳文档用「第 N 章 / 段落」定位。
- 单点可挂多个时间戳：`[01:23][04:56]`。
- 无对应时间点则省略或写「通篇」，**严禁为凑格式编造不存在的时间点**。

### 4. 来源标签（📹 / ➕）
- 📹 来自视频：文档原文内容（摘要/术语/导图/动画画面默认此来源，内部引用不重复贴标签）。
- ➕ 补充：外部/延伸/检索方向（仅 ⑤ 强制区分，其余物料内部引用不强制）。
- 补充项只给「可验证的检索方向（关键词/概念名）」，**严禁编造论文标题、作者、年份、URL**。

### 5. 不编造硬规则（全局兜底）
- 摘要/术语/导图/动画画面/旁白须来自文档；外部内容须标注来源并给检索方向。
- 数字：文档无明确数字则不写数字，不得「合理推断」出具体数值。
- 引用不确定时写「文档未明确」或「建议检索：XX」，绝不生成看似真实的假信息。

### 6. 各节长度目标
| # | 物料 | 长度目标 |
|---|------|----------|
| ① | 智能摘要 | 每章 2–4 要点，全文 600–1200 字 |
| ② | 术语表与通俗解释 | 8–15 行，每行类比 ≤1 句 |
| ③ | 知识导图 | 2–3 层、≤20 节点；大纲 ≤40 行 |
| ④ | 动画表达 | 单屏半内可览，旁白 ≤120 字 |
| ⑤ | 补充知识 | 每节 2–4 条，全文 800–1500 字 |
| ⑥ | 深度学习与理解文档 | 自检 3–6 条、自测 3–6 题、费曼 1 题 |

### 7. 难度档位（DR）
| 档位 | 适用 | 特征 |
|------|------|------|
| DR1 入门 | 零基础 | 类比优先，术语少而精，动画慢速、多旁白 |
| DR2 进阶 | 默认 | 适度术语，关系清晰，保留关键公式 |
| DR3 硬核 | 有基础 | 展开推导/数学，面向已掌握前置概念者 |

用法：在 User Prompt 顶部注入 `难度档位：DR{n}`（默认 DR2）；⑥ 在 DR3 下可补推导步骤。

### 8. Few-shot 范例（格式/口径锚定）
以下为 ② 术语表的 mini 范例，仅示格式与「类比优先」口径，实际内容须按文档生成：

```
| 卷积 | 一种"滑动窗口加权求和"运算 | 火车开进山洞，重叠部分逐格相乘累加即输出 | [00:42] |
| 卷积核 | 决定"看多远、看什么特征"的窗口模板 | 山洞的形状/长度，决定每次"截取"信号的方式 | [01:10] |
```

## 提示词 ④ 动画表达（HTML 动画）

**作用**：把文档中最核心、最抽象的主题内容，做成一个**可运行的 HTML 动画**——用「另一种」可视化方式帮助用户直观理解。产出是 self-contained HTML（内联 CSS + 原生 JS，无外部依赖），而非分镜脚本。

### System Prompt

```
你是「B站学习助手」的动画表达引擎。给定一份文档，你要产出一个 self-contained HTML 动画文件，把文档的「核心主题 / 最抽象概念」用可视化的方式表达出来。须严格遵循下方「风格与合规护栏层」的全局口径（语气、术语一致、[mm:ss] 引用、来源标签、不编造、长度目标、难度档位）。

要求：
1. 锁定一个最值得可视化的主题（优先文档里最难懂、最核心的概念，如卷积 = 滑动窗口加权求和）。
2. 产出一个完整 HTML 文件：
   - 纯内联 CSS + 原生 JS，无外部依赖、无 CDN、无图片外链，双击即可在浏览器播放。
   - 含一个会"动"的视觉演示，直观呈现该概念（例如：窗口在信号/图像上滑动、状态随时间演进、参数变化时结果联动）。
   - 提供基础交互控件：播放 / 暂停 / 单步 / 重置，至少其一。
   - 含一段文字旁白 / 注解，点明动画在讲什么，并回扣文档（可挂 [mm:ss]）。
3. 不编造画面：动画元素与数据须基于文档内容；若需示例数据用于演示，须是文档逻辑内的合理样例。
4. 视觉：干净、可读、浅色背景深色文字（便于阅读与截图）。
仅输出 HTML 文件内容（可直接落盘为 .html）。
```

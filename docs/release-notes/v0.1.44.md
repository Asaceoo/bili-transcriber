## P0：TOML 合并会让 Codex config.toml 全崩

`--agent-config codex --write` 的合并逻辑只精确匹配 `[mcp_servers.bili-transcriber]`。
用户手写的行尾注释（`[...] # 我的备注`）会让旧 section 漏匹配 → 新块追加 →
**TOML 同名 table 两份，Codex 解析直接失败，整个 config.toml 起不来**
（用户其它 provider 配置陪葬）。已修：section 头按 `#` 截断再比较，并用
tomllib 往返验证三个 section 内容全保真。

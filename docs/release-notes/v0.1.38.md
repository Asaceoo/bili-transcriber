# v0.1.38 更新说明

本版本为质量收敛版本：对全部核心模块完成三轮对抗性审查（工具实现者 / 审查者 / AI 使用方三视角、多轮迭代），累计修复 10 个真实缺陷 + 1 处文档欠账，全部以真实运行报错为依据修正，全量测试 261 项通过，真机验证通过。

## 修复

### 转写与任务管线
- **修复空闲模型卸载永久失效**：shutdown 哨兵消息消费后未调用 `task_done()`，导致任务计数永久大于 0，空闲卸载与线程池重建的"忙碌"判定永远成立（实测复现：shutdown 后 unfinished_tasks=2 不归零）。
- **修复用户通知全部静默失效**：UI 通知包装函数误写为自我递归，递归错误被自身异常捕获吞掉，全部 16 处用户提示（已入队 / 已暂停 / 删除成功等）从未真正弹出。
- **修复转码失败毒化断点续跑**：PyAV / ffmpeg 全部转码失败时残留半截 wav 文件，会被"文件已存在则复用"的续跑逻辑当成有效缓存直接喂给转写器；现失败时自动清理半截输出。

### 转写引擎
- **修复 SenseVoice 无时间戳句段时间戳重叠**：降级路径下所有句段被赋予相同的 (0, 30s) 区间，且最后一块超出实际时长；现改为按 token 占比顺序分配，句段互不重叠且不超块长。

### UI
- **修复历史页搜索框从未生效**：搜索过滤函数自首个版本起就是死代码（无任何调用点），定时器每次用无过滤整表覆盖；现搜索框即时生效、历史表带过滤刷新。

### 讲义生成
- **修复单帧截取失败丢弃全部讲义**：截取时刻可能越过视频结尾导致截帧失败，异常直接抛出使整个讲义被跳过、已成功帧全部浪费；现时刻自动钳制到视频时长内，单帧失败降级跳过。

### 其他平台
- **修复快手视频主键冲突**：页面解析全部失败时兜底返回固定 ID，两个不同视频会共享历史库主键、互相顶替；现改为基于链接哈希的稳定唯一 ID。

### 运行时与发布工具
- **修复 GPU 运行时 PATH 无限膨胀**：每次转写都重复把 DLL 目录前置到 PATH（无幂等保护）；现同目录只注册一次，且不影响"无 GPU 包回退 CPU"的判定。
- **修复发布脚本 2GB 内存峰值**：Releases 资产上传把最大 2.08GB 的 GPU 包整份读入内存；现改为文件流式上传（本地 HTTP 服务器闭环验证字节级一致）。
- **Cookie 导出脚本加固**：ego lite 导出 B 站 cookies 时，若未登录（缺 SESSDATA / bili_jct / DedeUserID）显式告警，不再静默写出无效文件。

### 文档
- 修正 v0.1.37 手册快照头部版本声明；明确 VAD 开关仅对 Whisper 引擎生效（qwen3-asr / SenseVoice 不使用该参数）。

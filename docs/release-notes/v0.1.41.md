两个影响所有桌面端用户的缺陷：程序会自己消失，以及双击后不是独立窗口而是被丢进浏览器。都已经在打包产物上真机复现、定位到根因并验证修复。

## 修复 1：程序开着几分钟自己退出

**现象**：窗口开着，什么都没动，过一会儿整个程序没了；日志里只有一行「日志系统已初始化」，没有任何报错，退出码 0。

**根因**（`webview/platforms/winforms.py`）：

```python
cache_dir = tempfile.TemporaryDirectory().name   # private_mode 下的默认值
```

`TemporaryDirectory()` 实例创建后**当场被回收**，其终结器把这个临时目录删掉，而 WebView2 还在往里读写用户数据 —— 渲染进程崩溃，窗口消失。NiceGUI 的 `check_shutdown` 线程发现窗口进程已死，调用 `core.stop_and_exit()`，于是整个程序静默退出。

**修法**：在 `ui.run()` 之前把 WebView2 的用户数据目录固定下来：

```python
nicegui_app.native.start_args["storage_path"] = str(DATA_DIR / "webview2")
```

第一版写成 `native.settings["storage_path"] = …`，开窗子进程直接抛

```
KeyError: "Cannot add new key 'storage_path'. Only existing keys can be modified."
```

`webview.settings` 是只允许改已有键的 `ImmutableDict`（`webview/util.py`），多塞一个键会让窗口根本起不来。`start_args` 才是 `webview.start(**…)` 的入参，才是对的入口。

目录不再被回收，顺带让不同安装目录的实例各用各的 profile，不再争抢同一个 WebView2 目录。删掉 `data\webview2\` 等于重置界面缓存，不影响任务历史。

## 修复 2：双击弹出浏览器，不是独立窗口

两个独立原因叠在一起：

**① `window_size` 会强制 native，`native=False` 是空的。**

```python
# nicegui/ui_run.py
if window_size: native = True
```

早期代码传了 `window_size=(980, 720)` 又传 `native=False`，实际一直走原生窗口；日志里打印的 `use_native=False` 只是本地变量的值，从未生效。现在只在确实要原生窗口时才传 `window_size`。

**② 「已有实例在运行」分支直接开浏览器然后退出。**

冷启动要导入 torch/transformers，窗口 10–20 秒才出现。用户以为没反应又双击一次 —— 第二个进程发现互斥体已被占用，就 `webbrowser.open()` 然后 `return`。这就是「一点就弹浏览器、接着一闪就没了」。

现在第二个进程改为**轮询 `FindWindowW` 最多 30 秒**，等到窗口就 `ShowWindow(SW_RESTORE)` + `SetForegroundWindow` 提到前台，然后自己退出；确实唤不到窗口且当前是原生模式时弹 `MessageBoxW` 说明，不再开浏览器。

## 现在的默认行为

| 情况 | 表现 |
|---|---|
| 系统有 WebView2（Win10/11 默认自带） | 双击 → **独立程序窗口**（980×720） |
| 没装 WebView2 | 自动退回浏览器，功能一致 |
| 想强制浏览器 | `BILI_FORCE_BROWSER=1` |
| 想强制窗口 | `BILI_FORCE_NATIVE=1`（需先装 WebView2 运行时） |
| **单文件版**（`bili-transcriber-single-*.exe`） | 仍走浏览器：onefile 每次运行解压到临时目录、退出即删，原生窗口在里面不稳定，所以构建时用运行时钩子固定了浏览器模式 |

托盘「打开主窗口」在原生模式下是把窗口提到前台，不再抛浏览器标签页。

## 其他改进

- **spawn 子进程早退**：源码模式下 `multiprocessing` 以 `__mp_main__` 重执行模块会再跑一遍入口，新增 `_is_spawn_child()` 早退，不再抢端口、不再多开。
- **窗口就绪看门狗**：后台线程记录原生窗口就绪耗时（`原生窗口已就绪(进程启动后 N 秒)`），60 秒仍未出现则记 `ERROR` 并提示可用 `BILI_FORCE_BROWSER=1` 兜底 —— 窗口态 exe 没有控制台，诊断信息只能进日志。
- **界面模式写进日志**：每次启动记一行 `界面模式:原生窗口(WebView2=True, show=False)`，便于用户反馈时定位。
- **退出时长记录**：`界面已退出,本次运行 N 秒`，用来区分「用户关窗」和「异常退出」。
